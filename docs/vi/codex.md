# Dùng với Codex

1. Mở Codex. Nếu cần chọn thư mục, tạo một thư mục tên **Framer** rồi chọn nó.
2. Gửi tin nhắn dưới đây và chờ Codex báo cài xong:

```text
Cài giúp tôi skill Design on the Flank từ:
https://github.com/Chien1618/design-on-the-flank/tree/main/skills/design-on-the-flank
Giữ đủ các tài liệu đi kèm. Nếu đã có bản cũ, giữ lại chỉnh sửa của tôi trước khi cập nhật.
```

3. Nếu Codex chưa nhận ra skill vừa cài, mở cuộc trò chuyện mới.
4. Mô tả component bạn muốn. Ví dụ:

```text
Dùng Design on the Flank tạo một component Framer: đám hạt 3D chuyển động theo chuột, khi cuộn thì gom thành một quả cầu. Cho tôi chỉnh màu, số hạt, tốc độ và mức phản ứng với chuột trong Framer. Trả toàn bộ code trong một khung để tôi sao chép một lần. Tôi không biết code.
```

5. Sao chép toàn bộ code rồi làm theo [cách dán vào Framer](dua-vao-framer.md).

Codex sẽ tự tìm phần Framer, Three.js hoặc GSAP cần dùng. Bạn không cần chọn từng tài liệu. Nếu không cài được, dùng [cách đính kèm file bắt đầu](chatgpt.md) trong chat và gửi thông báo lỗi để Codex kiểm tra.
