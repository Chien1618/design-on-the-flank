## Returning and Controlling Tweens

All tween methods return a **Tween** instance. Store the return value when controlling playback is needed:

```javascript
const tween = gsap.to(".box", { x: 100, duration: 1, repeat: 1, yoyo: true });
tween.pause();
tween.play();
tween.reverse();
tween.kill();
tween.progress(0.5);
tween.time(0.2);
tween.totalTime(1.5);
```
