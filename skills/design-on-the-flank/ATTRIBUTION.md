# Sources

This package contains 20 source skills and 6 supporting reference documents, split into 384 topic files. One entry skill routes to the appropriate files; this is not 20 separately installed skills.

- Framer Labs / fredm00n: 12 skills (Framer components, Framer plugins, 10 Three.js skills) and 6 references from the supplied handoff. Original repository: https://github.com/fredm00n/framerlabs. [MIT notice](licenses/framerlabs-MIT.txt).
- GreenSock: all 8 skills from https://github.com/greensock/gsap-skills at commit `aed9cfd3277740755f6bfc1155c7aa645403b760`. [MIT notice](licenses/gsap-skills-MIT.txt).

The UI/UX Pro Max document was excluded at the owner's request. No related scripts or data are included.

Source bodies are preserved except relative link repairs. Headings split the source into individually readable topics without splitting code fences. `source-manifest.json` records source hashes, adapted hashes and topic mappings. Imported examples are snapshots, not a claim of current Framer compatibility. Package integration guidance explains required adaptation.

The handoff's portable operating rules are represented in the entry skill and the Framer, updates, integration and verification references. Personal machine paths, a local font breakpoint preset and blanket unlink annotations are not imposed on users.

The root license applies to original Design on the Flank material only. Upstream MIT material retains its MIT permissions, including redistribution; the package's branding restrictions do not restrict those source documents. Library packages, models, images and other runtime assets have their own terms.
