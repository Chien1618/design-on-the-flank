# Đưa nội dung lên website

Dùng [landing.vi.md](landing.vi.md) cho trang giới thiệu. Các trang hướng dẫn nằm trong [docs/vi](../docs/vi/bat-dau.md). Khi đưa lên CMS, đổi link tương đối sang URL trang tương ứng.

| Nút trên web | Đích trong repo |
|---|---|
| Cài với Codex | docs/vi/codex.md |
| Dùng với ChatGPT | docs/vi/chatgpt.md |
| Tải file bắt đầu | downloads/design-on-the-flank-knowledge.txt |
| Tải gói Claude | downloads/design-on-the-flank-skill.zip |
| Dùng với Claude Code | docs/vi/claude-code.md |
| Dán code vào Framer | docs/vi/dua-vao-framer.md |
| Xem ý tưởng | docs/vi/prompt-mau.md |

Để tải trực tiếp từ GitHub, dùng tiền tố `https://raw.githubusercontent.com/Chien1618/design-on-the-flank/main/` trước đường dẫn downloads. Giữ tên file tải xuống. Nếu tự lưu các tài liệu trên website, sao chép cả thư mục `downloads/modules/`; file bắt đầu hiện vẫn dẫn tới tài liệu gốc trên GitHub.

Hiển thị phiên bản từ VERSION. Không viết “bảo đảm chạy ngay” hoặc “đã kiểm thử trên mọi nền tảng”. Gói cập nhật thủ công; file người dùng đã tải không tự đổi.
